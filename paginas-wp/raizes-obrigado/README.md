# Obrigado Raízes

HTML de um único widget HTML do Elementor na página WordPress `/obrigado-raizes/` em [escoladeintercessao.com.br](https://escoladeintercessao.com.br) (modelo Elementor Canvas, uma seção de largura total sem espaçamento).

É a página final de agradecimento do funil Raízes, alcançada pelo link de recusa do downsell em `/parabens-raizes-2/`.

O pixel da Meta vem do plugin PixelYourSite instalado no site inteiro, então o HTML não traz código de pixel de propósito.
